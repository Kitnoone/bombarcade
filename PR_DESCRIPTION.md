# Предложение для PR: Корабельный терминал и локальная игра по Wi-Fi

При запуске на компьютере Bombarcade теперь обслуживает ТВ и телефон внутри одной сети через WebSocket. Интерфейсы используют корпус из эскиза, живую карту и клавиши; сетевые команды проверяет сервер. При открытии со статического хостинга сохранён прежний режим ретранслятора.

Второй протокол добавляет три преследующих вируса, три попытки и 40 секунд на восьмизначный код после 10 секунд показа. Пауза и переподключение замораживают таймеры и угрозы; повтор начинает новый поиск без первого протокола. Мастер управляет запуском, настройками и привязкой телефона. Для Windows есть запуск двойным щелчком и инструкция подключения.

Проверено: 41 тест логики и серверов, 26 браузерных LAN-проверок, сквозные сценарии BroadcastChannel и реального обработчика ретранслятора с локальной SQLite, синтаксис 22 JS-файлов. Сняты ТВ 1920 × 1080 и телефон 360 / 390 / 430 px. Физический телефон и задержка по реальному Wi-Fi ещё требуют проверки. Живой ретранслятор не менялся.
